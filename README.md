# Felis Plug for EZVIZ

Unofficial Sailfish OS client for EZVIZ smart plugs.

## Features

- Automatic smart plug detection
- ON/OFF control
- Online/offline status
- Manual refresh
- Persistent session without storing the password
- MFA support
- Czech and English localization
- Easy support for additional translations
- Sailfish cover with plug statistics

## Requirements

- Sailfish OS
- EZVIZ account

## Privacy and security

- Your EZVIZ password is never stored.
- Only the session token is stored locally for subsequent launches.

## Disclaimer

Felis Plug is an unofficial client and is not affiliated with, endorsed by,
or supported by EZVIZ or Hikvision.

The application uses an unofficial/reverse-engineered EZVIZ consumer API.
Changes to the EZVIZ service may therefore cause the application to stop
working.
